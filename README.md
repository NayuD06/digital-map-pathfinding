# Digital Map Pathfinding

Đề tài: **Khảo sát bản đồ số và thuật toán tìm đường** (Dijkstra, A*) trên bản đồ một quận từ OpenStreetMap.

## Cấu trúc

```
BE/   FastAPI + OSMnx + NetworkX   → http://localhost:8000
FE/   React + Vite + Leaflet       → http://localhost:5173
```

FE và BE chạy riêng, mỗi bên một port. Xem hướng dẫn chạy trong [BE/README.md](BE/README.md) và [FE/README.md](FE/README.md).
